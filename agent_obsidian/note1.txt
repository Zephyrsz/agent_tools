Vault(保险库)就是 Obsidian 对"你的笔记库"的称呼——本质上**就是你电脑上的一个普通文件夹**。你在 Obsidian 里写的每条笔记,都是这个文件夹里的一个 `.md` 纯文本文件;附件图片就是文件夹里的普通图片文件。Obsidian 只是一个"打开这个文件夹来编辑"的客户端,数据本身完全在你本地,用访达/文本编辑器都能直接打开。

一个 vault 文件夹内部大概长这样:

```
MyVault/              ← 这个文件夹就是 vault
├── .obsidian/        ← Obsidian 的配置(主题、插件等)
├── 日记/
│   └── 2026-07-07.md
├── 工作笔记.md
└── attachments/
    └── 截图.png
```

判断一个文件夹是不是 vault 很简单:里面有 `.obsidian` 隐藏目录的就是。

## 怎么找到你的 vault 路径

最快的方法,在 Obsidian 里:

1. 看左侧**文件列表任意一个文件**,右键 → **"在访达中显示"**(Show in system explorer / 在文件管理器中显示)——弹出的窗口往上一层就是 vault 根目录
2. 或者点左下角的 **vault 切换图标**(像个保险箱),悬停在 vault 名字上通常会显示完整路径;"Manage vaults" 界面里也列出了每个 vault 的位置

命令行找也可以(macOS 上):

```bash
# Obsidian 记录了所有打开过的 vault
cat ~/Library/Application\ Support/obsidian/obsidian.json | python3 -m json.tool
```

输出的 `vaults` 字段里每一项的 `path` 就是 vault 的绝对路径。

或者直接搜文件系统里哪些文件夹含 `.obsidian`:

```bash
find ~/Documents ~/Desktop -name ".obsidian" -maxdepth 4 -type d 2>/dev/null
```

拿到路径后,上一条回复里的方案就都能用了——比如把这个路径喂给 filesystem MCP server,或者 Python 里 `Path("你的路径").rglob("*.md")` 直接遍历所有笔记。
